# ウェルネスの森を守る会のサイトの開発について
## vercel.jsonの記述の説明
このプロジェクトの `vercel.json` には以下の配信ルールが設定されています。
1. **検索エンジンの非公開化（noindex）**
   サイト全体("source": "/(.*)")がGoogleなどの検索結果に引っかからないようにしています。
   →"X-Robots-Tag": "noindex, nofollow"
2. **CSVファイルのキャッシュ無効化**
   `activity.csv` や `album_list.csv` などのCSVデータ("source": "/(.*\\.csv)")は、
   更新が即座に画面へ反映されるよう、Vercelおよびブラウザ側のキャッシュを完全に
   無効化（`s-maxage=0`）しています。
   →"Cache-Control": "... s-maxage=0"
   ※CSV以外の画像やHTML/CSSはキャッシュされるため、通信量をsaveし通信速度を高める事になる。

## 開発環境について
このサイトの開発のためにインターネット上で広く無料で利用可能な資源を活用している

GitHub：主にhtmlやほぼ固定的に利用するデータの保管場所
Vercel：そのセキュリティー機能を利用してDomeinを管理している
Googleドライブ：画像を保管するimagesフォルダーや世話人の共用フォルダーでもあり、出欠登録データや、きょうつうの保管をするsewaフォルダー、また、Google Apps Script（GAS）を使ってa.出欠登録、b.画像データのアップ、c.画像ファイルIDのリストファイル（album_list.csv）の作成とGitHubに5分毎に転送、d.お知らせファイル（news.csv）のGitHubに5分毎に転送操作を自動化をさせている

これらの開発環境へはwellnessnomori@gmail.comアカウントでログインされる

## パスワードの有効期限
仕様のまとめ（最終確認）
認証維持: パスワード認証成功後、キーボードやマウスなどの操作（mousemove, keydown, click 等）がある限り、全ページ共通で10分間の期限が常に最新に更新されます。

自由往来: 最後の操作から10分以内であれば、PW不要ページ（お知らせ、活動予定、アルバム等）とPW必要ページ（メンバー専用メニュー、出欠、写真アップ等）を何度行き来してもパスワード入力はスキップされます。

自動失効: サイト内のどのページにいても、操作がないまま10分間が経過した時点で権限は失効（タイムアウト）します。

即時失効（ログアウト）: 三本線メニュー等の「ログアウト」ボタンが押された場合は、10分の経過を待たずに即座に権限が満了（失効）します。

## サイトの構成
1. index.html（サイトの表札とも云える）
　 画面中央のロゴマークをクリックしてtop.htmlにリンク
2. top.html（メイン・ページ）
　 この下にnews.html、schedule.html、album.html、member.html、aboutus.htmlの5つのページがリンクする
   4つのボタンとフッターに私たちについてへのリンクがある
   このページにはハンバーガー・メニューはない
3. news.html（お知らせ）
　 sewaフォルダー内のaboutus.txtにリクさせている
4. schedule.html（活動予定）
　 GitHub内のactivity.csvから活動日のリストを表示（システム日付以降分のみ）しメンバーが指定した活動日の詳細が集合場所を示す画像（mapn.png(n:連番)）と合わせて表示
   mapn.pngはサイト管理者が必要に応じてマップアプリをトリミングして作成しGitHub内に直接保管する
6. album.html（アルバム）
　 GitHub内のalbum_list.csvの活動日のリストから年月単位のリストを作成（システム日付以前分のみ）しメンバーが選択した年月分の画像を一枚づつ表示する
   画像上には＜と＞のボタンも半透明に表示され次々と循環して画像を表示する
   Downloadボタンが画像の下にあり、捜査中のスマホやPCに保管も可能
7. member.html（メンバー専用ページ）
　 この下にsanka.htmlとshashin_up2.htmlにリンクする
   共通のパスワードを入力して承認されると、出欠登録、画像をアップするボタンが表示さsる
   共通パスワードは一定時間有効でこの時間内なら出欠登録、画像をアップ以外のページ移動していても共通パスワードの入力を求められない
   先の2つのボタンのほかにログアウト（共通パスワードの有効期限は失効）、トップページに戻るボタンもある
8. aboutus.html（私たちについて）
　 sewaフォルダー内のaboutus.txtを表示する
9. sanka.html（出欠登録）
　 GitHub内のactivity.csvから活動日のリストを表示（システム日付以降分のみ）し、メンバーが指定した活動の詳細が次画面に表示される
   名前（ニックネーム等）、参加・不参加・未定の選択ボタン、メモ（オプション）を入力して確認ボタンをクリックすると確認画面が表示され登録か訂正が出来る
   登録されると入力内容はsewaフォルダー内のsanka.csvファイルに保存される
   sewaフォルダーにアクセスできるメンバーこのファイルを表計算アプリに読み込みピボット展開で一覧表の方で見ることが出来る
   登録は同一のイベント、同一の名前で何度でも登録が可能でsanka.csvには登録日時が記録されているので最新のものだけを採用できる
10. shashin_up2.html（画像アップ）
　 GitHub内のactivity.csvから活動日のリストを表示（システム日付以前分の6件のみ）し、メンバーが指定した活動の詳細が次画面に表示される
   名前（ニックネーム等）、操作中のスマホやPC内の画像ファイルを複数選択し、時に選択の一部を除外するためにサムネイル画像に×印がある
   送信ボタンをクリックすると当該の画像はGoogleドライブのimagesフォルダーに転送されるが枚数に応じて相応の時間がかかる
   GASの実行が5分毎に行われ、imagesフォルダーに保存されている画像ファイルID（album_list.csv）を更新し、GitHub内に転送されるのに最大、5分必要だ
   つまり、画像をアップ後に最大5分経過すればサイト内のアルバムに反映される
   関係者以外の不埒ないたずらを防止するために、メンバー自身で画像を削除する機能はないので、必要ならサイト管理者に連絡の上で削除依頼をする
   
## 共通仕様
幾つかの機能が共通化されている

ハンバーガー・メニュー（画面の右上にある三本線）ではメインページ、お知らせ、活動予定、アルバム、メンバー専用ページ、ログアウトに直接リンクさせている
但し、今表示中の画面にリンクする項目はなく、ログアウトはindex.html（表札）にリンクするとともに共通パスワードの有効期限を消去する

フッターとして著作権主張と私たちについてへのリンクされている
